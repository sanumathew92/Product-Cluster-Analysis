# Product-Cluster-Analysis
Product Cluster Analysis
This project focuses on applying data-driven techniques to analyze historical sales data and uncover meaningful patterns in product behavior. By leveraging machine learning methods such as clustering, products are grouped based on similarities in sales performance, variability, and demand characteristics.
The analysis enables the identification of key product segments such as high-performing products, slow-moving inventory, seasonal items, and stable performers. These insights support better inventory management, improved product assortment planning, and more targeted business strategies.
